
## 1. What is Flow Builder?
Flow Builder is a  tool used to automate tasks  without writing code. It is very easy to use because we can create automation by dragging and dropping elements. With this tool we can collect information, send emails automatically, update records.

## 2. Types of Flows 
    Explain: 
     Screen Flow 
     Record Triggered Flow 
Screen Flow:
 Screen Flow is used for interaction with users through screens. It is used to collect information from users, display messages, and guide for completion of a task. It works with buttons, text fields, and options.

Record-Triggered Flow:
Record-Triggered Flow runs automatically when a record is created, updated, or deleted in Salesforce. It is mainly used to automate background processes such as updating fields, sending notifications, creating records, or performing actions without user interaction.

## 5. Manual vs Automated Process 
Manual Process:
Manual process is completed by people without automation. Users perform tasks step by step, such as entering data, sending emails, updating records, and checking information manually. Manual processes take more time and may lead to human errors.

Automated Process:
An automated process is completed automatically which is done by using tools . The system performs tasks such as sending notifications, updating records, creating tasks, and processing data without human involvement. Automated processes save time, improve accuracy, and increase efficiency.

## 6. Reflection 
    Why automation matters in enterprise systems
Automation is important in enterprise systems because it makes work easier and faster. Instead of doing repeated tasks manually, the system can do them automatically. This helps save time and reduce mistakes.<br>
Examples like  Salesforce automation can automatically send emails, update records, create reminders, and notify users. It also helps employees focus on important work instead of doing the same task again and again.
Therefore automation improves productivity, accuracy, and makes business processes simple and efficient.
