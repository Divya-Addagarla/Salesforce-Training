
#  1. What is Salesforce Platform? 
Salesforce platform is a cloud software platform used to store customer data, automate business work, and build business applications.
Companies use Salesforce to
  - Store customer details
  - Track sales
  - Handle customer support
  - Automate tasks
  - Build apps for employees or customers
# 2.
#  What is App 
  App is a collection of tools, tabs, and features used for a specific business purpose
Ex:
  A Sales App may contain: Customers,Leads,Opportunities,Reports
  
# What is Object 
 Object is like a database table that stores information.
A Student Object stores:
Student Name
Roll Number
Class
Phone Number

# Whta is Tab
 Tab is used to open and access an object 
Ex : 
 When you click the Accounts Tab, it opens Account records.

# 3.  Configuration vs Coding 
Configuration means Customizing Salesforce without writing code.It is also called as Low-code development
Coding means writing code to create advanced features.
